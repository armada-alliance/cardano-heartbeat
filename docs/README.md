# Welcome to the Cardano Heartbeat (CEM)

The Cardano Heartbeat (Crisis Event Management Platform) is a Project Catalyst fund-6 proposal to develop a platform for managing the Cardano blockchain in disaster or crisis events. [View the full proposal on IdeaScale](https://cardano.ideascale.com/a/dtd/Cardano-Heartbeat-CEM-%F0%9F%92%9E/366924-48088)

This Project is a work in progress and is currently being developed by a team from the Armada Alliance organization.
